# Анонимки

Telegram-бот анонимных сообщений на Cloudflare Workers + D1 с Mini App.

Люди пишут боту, ты видишь только придуманное имя вроде «Тихий лис». Отвечаешь в приложении или реплаем в чате.

## Запуск

1. Залей папку в GitHub-репозиторий (`wrangler.toml` должен лежать в корне).
2. Cloudflare → Storage & databases → D1 → Create database, имя `anonbot`.
3. Открой базу → Console → вставь содержимое `schema.sql` → Execute.
4. Скопируй id базы в `wrangler.toml` вместо `ВСТАВЬ-ID-БАЗЫ` и закоммить.
5. Workers & Pages → Create → Import a repository → выбери репозиторий → Deploy.
   Имя воркера должно совпадать с `name` в `wrangler.toml` (`anonbot`).
6. Воркер → Settings → Variables and secrets → добавь секреты:
   - `BOT_TOKEN`: токен от @BotFather
   - `OWNER_ID`: твой Telegram id (число)
   - `SECRET`: любая случайная строка из букв и цифр, без пробелов и знаков
7. Открой в браузере `https://<воркер>.workers.dev/setup?key=<SECRET>`.
   Должно вернуться `"ok":true` дважды: это ставит вебхук и кнопку «Входящие» в чате с ботом.
8. Напиши боту с другого аккаунта и открой приложение.

## Как это работает

- Имя отправителя строится из его id и твоего `SECRET`, поэтому одно и то же у каждого человека. Настоящий id в приложение не уходит.
- Ответ можно написать в приложении или реплаем на сообщение в чате. Реплай `/ban` банит человека.
- Отвеченные сообщения удаляются через 7 дней, любые через 30, чистка раз в сутки. Вручную: «Очистить отвеченные».
- Больше 5 сообщений в минуту от одного человека бот не принимает.
- Приложение проверяет подпись Telegram и пускает только `OWNER_ID`.

## Локальная проверка

```bash
npm install
npx wrangler dev
```
